# RevenueOS V1
RevenueOS is a deliberate revenue operating system: agents propose and execute bounded work, while people retain authority over material spend, launches, and policy. V1 ships a high-fidelity local preview with seeded operational data, then swaps to Supabase persistence.

## Surfaces
Command, Agents, Opportunities, Experiments, Revenue, Intelligence, Graveyard, Approvals, and Settings are primary routes. Actions either update browser-session state or explicitly state that a configured persistence layer is required.
